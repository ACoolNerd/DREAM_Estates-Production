# Enterprise Roadmap

## Phase 0 — Governance
Brand hierarchy, RASCI, data classification, repository policy, verified authority, rights/privacy gates.

## Phase 1 — Production vertical slice
Public site → inquiry → CRM contact/opportunity → project → task → approval → media asset → distribution eligibility → audit event.

## Phase 2 — Platform core
Authentication, organizations/tenants, role model, Supabase/PostgreSQL, RLS, API, audit, admin, project portal, CRM.

## Phase 3 — Creative/media engine
Asset registry, versions, rights, privacy classification, approvals, aspect-ratio derivatives, publishing queue, analytics references.

## Phase 4 — n8n/MCP
Automation gateway, signed events, least-privilege credentials, retries, dead-letter handling, workflow registry, operator dashboard.

## Phase 5 — Enterprise controls
Dev/staging/prod separation, CI/CD, secret/dependency scanning, backups/restore tests, incident response, access reviews, vendor register, privacy/legal review.

## Phase 6 — Authorized domain modules
Healthcare, mortgage/NMLS-aware, and MLS/RESO-aligned connectors remain disabled until contracts, authority, vendor controls, policies, and validation are complete.

## Quality gate
Score 1–100: Architecture, Security, Maintainability, UX, Mobile, Accessibility, Data Model, Authorization, API, CRM, Automation, Auditability, Documentation, Brand Fidelity, Deployment Readiness.

**Target: 97+** for production release. A design/specification can score 97+ independently, but the deployed platform must not inherit that score until controls are implemented and verified.
